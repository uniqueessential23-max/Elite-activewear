# VOLT | Elite Activewear Commerce

A premium, production-ready mobile eCommerce application built for elite performance brands.

## Features
- **Modern Mobile UI**: High-fidelity design with glassmorphism and neon accents.
- **Dynamic Catalog**: Full product browsing with category filtering.
- **Persistent Cart**: Real-time quantity management and price calculation.
- **Formspree Integration**: Secure checkout and order submission.
- **Mobile First**: Optimized for touch interaction and responsive layouts.

## Deployment to Vercel
This project is structured for immediate deployment.
1. Push this code to a GitHub repository.
2. Connect the repository to Vercel.
3. Vercel will automatically detect the static files and deploy them.

## Local Development
Since this is a Vanilla JS application, you can simply:
1. Open `index.html` in any browser.
2. Or use a local server like `Live Server` in VS Code.

## Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom properties, Flexbox, Grid, and Backdrop-filter for glassmorphism.
- **JavaScript**: ES6+ for state management and routing.
- **Formspree**: Backend form handling.
- **Google Fonts**: Anton & Inter.
